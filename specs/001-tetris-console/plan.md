# Implementation Plan: Windows Console Tetris (C++)

**Branch**: `001-tetris-console` | **Date**: 2026-05-08 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/001-tetris-console/spec.md`

## Summary

实现一个 C++ Windows 控制台版俄罗斯方块游戏。项目使用 C++17 标准，仅依赖标准库和 Windows 控制台 API（无需第三方库）。核心架构分为 5 个模块：Game（主循环）、Board（棋盘逻辑）、Piece（方块）、Renderer（渲染）、Input（输入）。渲染使用 `WriteConsoleOutput` 实现双缓冲，支持彩色显示。输入使用 `_kbhit()` + `_getch()` 实现非阻塞键盘读取。代码模块化清晰，main.cpp 仅负责初始化。

## Technical Context

**Language/Version**: C++17（兼容 C++20）  
**Primary Dependencies**: 仅标准库 + Windows 控制台 API（kernel32.dll 中的控制台函数）+ `<conio.h>`（键盘输入）  
**Storage**: N/A（无持久化存储需求）  
**Testing**: 手动验收测试（基于 spec.md 中的 Acceptance Scenarios）  
**Target Platform**: Windows 10/11，PowerShell / Windows Terminal  
**Project Type**: CLI 控制台应用（单可执行文件）  
**Performance Goals**: 60fps 渲染刷新率，方块下落间隔 800ms → 100ms（随等级变化）  
**Constraints**: 内存 <50MB，exe 大小 <500KB（静态链接），ASCII 字符优先  
**Scale/Scope**: 单一 .exe，~1500 行 C++ 代码，5 个模块

## Module Design Overview

### 1. Game（游戏管理器）

**职责**: 主循环、状态管理（Running / GameOver）、分数/等级/行数追踪、方块生成、下落定时器、调度 Input/Renderer 更新。

**核心接口**:
```cpp
class Game {
public:
    void run();              // 启动主循环
private:
    void handleInput();      // 处理输入 → 操作 Piece
    void update(float dt);   // 更新逻辑（下落、锁块、消行）
    void render();           // 调用 Renderer 绘制
    void spawnPiece();       // 生成新方块
    void lockPiece();        // 固定方块到 Board
    void clearLines();       // 消除满行并计分

    Board board;
    Piece currentPiece;
    Renderer renderer;
    Input input;
    int score, lines, level;
    bool running;
};
```

### 2. Board（棋盘）

**职责**: 10x20 网格存储、碰撞检测、方块锁定、行消除、边界检查。

**核心接口**:
```cpp
class Board {
public:
    bool canPlace(const Piece& piece) const;  // 碰撞检测
    void place(const Piece& piece);           // 锁定方块
    int clearFullLines();                     // 消行（返回消除行数）
    bool isCellOccupied(int x, int y) const;
    Color getCellColor(int x, int y) const;
    
    static const int WIDTH = 10;
    static const int HEIGHT = 20;
};
```

### 3. Piece（方块）

**职责**: 7 种方块形状定义、旋转状态、当前位置、颜色。

**核心接口**:
```cpp
class Piece {
public:
    enum Type { I, O, T, S, Z, J, L };
    
    void moveLeft();
    void moveRight();
    void moveDown();
    void rotate();               // 顺时针旋转
    Type getType() const;
    int getX() const, getY() const;
    Color getColor() const;
    const int* getShape() const; // 返回 4x4 形状矩阵
};
```

### 4. Renderer（渲染器）

**职责**: 控制台绘制、颜色设置、双缓冲渲染、光标隐藏。

**核心接口**:
```cpp
class Renderer {
public:
    void init();                                // 初始化（设置编码、缓冲区大小）
    void render(const Board&, const Piece&, 
                int score, int lines, int level);
    void renderGameOver(int finalScore);
    void shutdown();
};
```

**渲染策略**: 使用 `WriteConsoleOutput` 的 `CHAR_INFO` 缓冲区做双缓冲。每帧构建完整画面到缓冲区，一次性写入控制台，消除闪烁。

### 5. Input（输入处理）

**职责**: 非阻塞键盘读取，将原始按键映射为游戏操作。

**核心接口**:
```cpp
enum class Action { None, MoveLeft, MoveRight, MoveDown, Rotate, HardDrop, Quit };

class Input {
public:
    Action poll();  // 非阻塞检测，返回当前帧的操作
};
```
